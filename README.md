## How to open and run in Google Colab

1. Go to [colab.research.google.com](https://colab.research.google.com) and sign in with your Google account.
2. Open the notebook:
   - **From GitHub:** choose **File > Open notebook > GitHub**, paste the repository URL, and select the notebook.
   - **From a file:** choose **File > Upload notebook** and select the `.ipynb` file.
   - **From Google Drive:** choose **File > Open notebook > Google Drive**.
3. To keep your own copy, choose **File > Save a copy in Drive**. Your copy is saved in the *Colab Notebooks* folder of your Drive.
4. Run each cell with **Shift + Enter**, or run everything with **Runtime > Run all**.

No installation is needed. Colab already includes numpy, pandas, scikit-learn and matplotlib.

## Running on your own computer (optional)

1. Install Python 3.9 or later.
2. Install the libraries:

   ```
   pip install numpy pandas scikit-learn matplotlib
   ```

3. Save the program as a `.py` file.
4. Run it:

   ```
   python filename.py
   ```

## Notes

- Run one experiment per cell so that each output stays separate.
